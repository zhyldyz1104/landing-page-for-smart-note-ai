Technologies used

Built with a modern stack.

Grouped by job, so you can see how it fits together at a glance.

Frontend

React Native + TypeScript with Expo — Router, Constants, LinearGradient & Metro. Custom components: NoteCard, AIButtons, NewNoteModal, BottomNav.

Backend — Firebase

Firestore stores notes, categories, timestamps & metadata. Authentication handles email / password login. Storage is ready for future media attachments.

AI Integration

Google Gemini Flash API via a custom useAI() hook — with retry logic, error handling, loading states, and a safe request wrapper.

State & Deployment

useNotes() for CRUD, stats, trash / restore & favorites. Deployed with Vercel (web) and Expo EAS Build (Android APK) at smartnotes.ai — DNS via Namecheap + Vercel.
